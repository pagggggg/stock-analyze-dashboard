# 進出場規則回測 (rule-backtest)

用歷史數據回答一個問題:**賣出時只看估值(PE)夠不夠?還是必須加上「基本面轉壞」才能控制風險?**

比較兩套規則,**進場條件刻意完全相同**,差異才能歸因到出場規則:

| | 策略 A:純 PE 進出 | 策略 B:PE 進場 + 基本面證偽出場 |
|---|---|---|
| 進場 | PE < 自身歷史 PE 中位數 | 同 A(且基本面未處於惡化狀態) |
| 出場 | PE > 自身歷史 PE 第 80 百分位 | (a) PE > 第 80 百分位、或 (b) EPS 連兩季年減、或 (c) 毛利率連兩季下滑 |

測試標的:**21 檔**,刻意混入不同類型以避免「只在成長股上測試」——
成長(2330 台積電、2308 台達電、2454 聯發科、3017 奇鋐、3661 世芯、2382 廣達)、
成熟(2412 中華電、1216 統一、1101 台泥、2886 兆豐金、2317 鴻海)、
循環(2327 國巨、2408 南亞科、2603 長榮、2002 中鋼、1301 台塑;**明知系統不適用,當對照組**)、
美股(AAPL、MSFT、TSLA、KO,以及 **INTC —— 曾經的成長股變衰退股**)。

> ⚠ 僅供研究,非投資建議。

## 結論在哪

兩份報告:

| 檔案 | 回答什麼 |
|---|---|
| **`rule_backtest.md`** | 純 PE 出場夠不夠?還是必須加上「基本面轉壞」才能控制風險? |
| **`era_robustness.md`** | **A/B/買進持有的結論,是不是只是「成長股大時代」的產物?** |
| **`entry_rule_backtest.md`** | 「PE<20 且 歷史PE百分位<50%」進場、持有1/3/5年,有沒有選時價值? |
| **`expected_value_backtest.md`** | 「期望值+安全邊際」(每季重算、三情境外推)進場,有沒有比較好? |

後兩份的共同結論值得先知道:**兩套規則相對「同期間隨便挑一天進場」都沒有展現穩定優勢**。
PE 規則在 12 組比較中輸 10 組;期望值法是 7 勝 5 負,但樣本小到與丟硬幣無異。
這個「任意日進場」基準是判斷擇時規則有無價值的關鍵對照 —— 少了它,
90~100% 的勝率會讓人誤以為規則很神,實際上那只是標的本身在這段期間上漲。

`era_robustness.md` 的三個擴充:
1. **樣本擴大**到 21 檔、混入成長/成熟/循環/美股
2. **分時代切段**:2008~2016(大噴發前)vs 2017~2026(大噴發時代),看結論會不會翻轉
3. **組合層級**:每日把資金等分給有部位的標的,對照全程等權買進持有(比單股更接近實戰)

**兩份報告的判斷句都是程式依回測指標自動生成的**——數字變結論就變,不是先寫好再套。

## 資料源(為什麼這樣選,實測後的決定)

| 資料 | 台股 | 美股 |
|---|---|---|
| 每日 PE | TWSE 個股日本益比 BWIBBU(**不吃 FinMind 額度**,可回溯 2005) | 自算:未還原收盤價 / 近四季實際 EPS |
| 季 EPS | FinMind 綜合損益表 | yfinance 財報日(含**共識 EPS**,可回溯 2010) |
| 毛利率 | FinMind(GrossProfit / Revenue) | SEC EDGAR XBRL(**Q4 須由全年減前三季推導**) |
| 股價 | yfinance(還原股利) | yfinance(還原股利) |

實測踩到、已處理的坑:
1. yfinance 的 `quarterly_income_stmt` 對 TSLA **只回 5 季**,長度不夠 → 毛利率改用 SEC EDGAR(66 季)。
2. SEC EDGAR 的 10-K **不單獨標 Q4** → Q4 = 全年 − 前三季。
3. SEC 同一期間會有多筆(重編/比較欄位)→ 一律取**最早送件**那筆,才是當時看得到的數字。
4. FinMind 免費版有每小時上限 → 全面檔案快取、可中斷可續跑。
5. **TWSE 抓取失敗曾被靜默當成「該月無 PE」寫入永久快取**(擴大到 21 檔時被限流才暴露):
   結果 1216、3661 整段 PE 變成 0 筆,回測卻照跑不誤。已修正為「只有**確定無資料**才快取,
   抓取失敗一律不快取並重試」,並在 `era_robustness.md` 逐檔標示 **PE 覆蓋率**,
   低於 80% 會標警告 —— 這種 bug 的可怕之處在於它不會報錯,只會讓結論悄悄建立在殘缺資料上。

## 時代穩健性的方法決定(era_robustness.md)

- **切段不重跑**:時代分段用的是「同一次回測」的淨值曲線切片,而不是各時代分開重新暖身。
  分開重跑會讓後段偷到「分位數已經穩定」的優勢,也會切斷跨段持倉。
- **短區間不硬算年化**:一段少於 250 個交易日就標「樣本不足」,不報年化
  (短區間年化會被指數放大,是常見的誤導來源)。
- **等權組合**:每日把資金等分給當日有部位的標的;全部空手就是現金(以 0% 計息,保守)。
  這假設可以無摩擦每日再平衡,**是樂觀假設**,報告中已標明。
- **切點與分類都是事後選的**:2017 這個切點、以及把 INTC 歸為「衰退」,
  都是**知道結果之後**才決定的,本身帶有後見之明。報告把這點寫在限制裡,不當成客觀事實。

## 方法上的關鍵決定(全部寫在報告裡)

- **口徑**:一律用 **trailing PE**。前瞻 PE 需要「歷史上每一天的共識 EPS」,免費源拿不到;
  用今天的共識回推過去就是前視偏誤。此限制對結論的影響方向已在報告第 6.2 節說明。
- **無前視**:PE 分位數用**擴張視窗**(只用當日以前的資料);財報用法定申報期/實際送件日;
  訊號 T 日產生、**T+1 日收盤**成交。
- **A/B 同起跑線**:起始日 = max(PE 暖身完成日, 基本面規則首次可評估日)。
- **過擬合防護**:參數只有題目給的 3 個、不做搜尋、不事後調整;暖身期三種設定併陳。
